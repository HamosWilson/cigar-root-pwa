# Hamos 的烟草生活 · 手机版（iOS PWA）

桌面版 `Cigar Root.exe` 的同一套界面与同一份数据，改造成能装进 iPhone 主屏幕的网页应用。
不依赖 Electron、不需要 Mac、不需要 App Store —— 用 Safari 打开、添加到主屏幕即可。

## 〇、线上地址（人在外面也能用）

```
https://hamoswilson.github.io/cigar-root-pwa/
```

- 仓库：`HamosWilson/cigar-root-pwa`（公开，**只有代码和演示数据**，个人库存不进去）
- 这是 https，Service Worker 会注册，**打开一次就整站缓存**：之后断网、开飞行模式都能开。
- 公开版首启是应用自带的演示数据。要换成自己的库：桌面版「备份」导出 JSON → 发到手机 → 手机「设置 · 恢复」选那个文件。

> 重新发布：`GH_TOKEN=... GH_USER=HamosWilson node publish_pages.mjs cigar-root-pwa`（纯 REST，不需要装 git）。
> 脚本会先把 `data/seed.js` 换成不带数据的占位，再把其余 24 个文件推上去并开 Pages。

## 一、现在怎么用（局域网，最快）

1. 双击本目录下的 `启动.cmd`（黑窗口别关，关了手机就连不上）。
2. 窗口里会打印两行地址，例如：

   ```
   本机： http://127.0.0.1:8080/
   手机： http://192.168.31.167:8080/
   ```

3. iPhone 连**同一个 Wi-Fi**，用 **Safari** 打开「手机」那一行。
4. 点 Safari 底部的「分享」→ 往下翻 → **添加到主屏幕** → 名称「烟草客」。
5. 从主屏幕图标打开，就是全屏、无地址栏的样子，和桌面版观感一致。

> 电脑和手机必须在同一个 Wi-Fi；换了网络，IP 会变，重新看 `启动.cmd` 打印的那一行。

## 二、数据

- 首次打开时，会把 2026-11-02 桌面版实库**整份**写进手机浏览器（28 支雪茄 / 13 款烟斗草 / 12 条品吸记录 / 8 条斗草记录），从那一刻起手机是**独立的一份**。
- 想搬数据：桌面版「备份」导出 JSON → 手机版「设置 · 恢复/导入」选那个 JSON。
- 反过来也一样：手机版「备份」导出，再导回桌面版。
- 数据只存在各自的浏览器/本机里，**不会自动同步**。真要天天两边对得上，下一步可以做一台小同步服务。

## 三、离线 & 换到 https

- 用 `http://局域网IP` 打开时，浏览器不给注册 Service Worker，**必须连着电脑才能开**。
- 把本目录整个丢到任意静态托管（GitHub Pages / Cloudflare Pages / 自己的 https），用 https 打开，
  就会完整离线：断网也能开、能看、能记，数据照旧在本机。

## 四、目录说明

| 路径 | 作用 |
| --- | --- |
| `index.html` | 入口（加了 iOS 主屏幕 meta、manifest、首次打开的手机字号校准） |
| `manifest.webmanifest` | 添加到主屏幕用的应用信息 |
| `icons/` | 图标：180（iOS 桌面）、192/512（PWA）、512 maskable |
| `css/app.css` | 桌面版原样式（未改） |
| `css/pwa.css` | 只做叠加：安全区、触屏、防自动放大 |
| `js/*.js` | 桌面版原逻辑（core.js 负责 `cigarrow.v1` 这份数据） |
| `js/pwa.js` | 注册 Service Worker、标记独立窗口 |
| `data/seed.js` | 内置初始数据（首次打开时写入 localStorage） |
| `sw.js` | 离线缓存（改了代码记得把 `VERSION` 加一） |
| `serve.mjs` | 零依赖静态服务器（给电脑跑，供手机访问） |
| `启动.cmd` | 双击启动上面的服务器 |

## 五、改代码之后

1. 改 `index.html` / `css` / `js`。
2. 把 `sw.js` 里的 `VERSION` 加一（例如 `...20261102c`），否则手机会一直吃旧缓存。
3. 手机上手势下拉刷新，或从主屏幕删掉重装。

## 六、已知边界

- 桌面版里「资料补全」联网查资料需要那台 worker 服务；手机版保留按钮，没有服务时就只查内置的离线资料库。
- 桌面版是 Electron 窗口，`window.hamosDesktop` 不存在时，缩放走 CSS `zoom`——手机上首次打开会把 130% 校准成 100%，之后以你在「设置」里调过的为准。
